# Добро пожаловать! 
Я AQA/SDET с коммерческим опытом ручного и автоматизированного тестирования веб-приложений. Основное направление работы — автоматизация тестирования на Java. В этом профиле собраны мои учебные проекты.

### 🛠 Стек

- **Язык программирования:** Java
- **UI-автоматизация:** Selenium WebDriver, Selenide
- **API-тестирование:** REST Assured, Postman
- **Тестовые фреймворки:** TestNG, JUnit 5
- **Отчётность:** Allure
- **Сборка проектов:** Maven
- **Базы данных:** PostgreSQL, MySQL

### 📂 Проекты

**1. [UI Automation Framework](https://github.com/msnchk/sdet-workshop) (2025)**

Автоматизация тестирования [демо-веб-приложения](https://www.globalsqa.com/angularJs-protractor/BankingProject/#/login) для управления банковскими клиентами

*Java, Selenium WebDriver, TestNG, Allure, Maven, Docker*

**2. [API Automation Framework](https://github.com/msnchk/sdet-workshop-api) (2025)**

Автоматизация тестирования REST API развернутого локально [сервиса](https://github.com/bondarenkokate73/simbirsoft_sdet_project). Проверки CRUD-операций над сущностями.

*Java, REST Assured, TestNG, Allure, Jackson, Maven*

**3. [UI Automation Tests Way2Automation](https://github.com/msnchk/way2automation-ui-tests) (2025)**

Проект автоматизации UI-тестирования учебных веб-страниц Way2Automation (на момент публикации сайт имел другой дизайн и структуру).

*Java, Selenium WebDriver, TestNG, Maven, Allure, Lombok*

**4. [WordPress API Tests](https://github.com/msnchk/wordpress-api-tests) (2025)**

Автоматизация тестирования REST API локально развернутого сайта на WordPress с дополнительной проверкой данных непосредственно в базе данных.

*Java, REST Assured, JUnit 5, MySQL, JDBC, Jackson, AssertJ, Maven*

**5. [Registration Form UI Tests](https://github.com/msnchk/registration-form-test) (2025)**

Проект автоматизации тестирования [веб-формы регистрации](https://practice-automation.com/form-fields/)

*Java, Selenium WebDriver, TestNG, Allure, Maven*


**6. [Kafka & RabbitMQ Tests](https://github.com/msnchk/rabbitmq-and-kafka-lesson) (2025)**

Реализация тестов для проверки отправки и получения сообщений, работы очередей и топиков.

*Java, Apache Kafka, RabbitMQ, TestNG, Maven, Jackson*

**7. [WireMock Tests](https://github.com/msnchk/wiremock-lesson) (2025)**

Автоматизация тестирования REST API с использованием WireMock. Реализация mock- и proxy-тестов, а также проверок на реальном API, [сайт](https://reqres.in/).

*Java, WireMock, REST Assured, JUnit 5, Maven, Jackson*
